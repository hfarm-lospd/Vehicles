## Implementation of a National Fleet Query

In this repository, you will find a file named ```fleet.py``` containing a small nested dictionary, which is an excerpt from the 2025 national fleet data. This nested dictionary is our toy data. It contains the number of motorcycles and buses categorized by geographical area, category (engine size for motorcycles and use type for buses), and Euro emission standard. For simplicity, toy data includes only two geographical areas and two emission standards.

In the same file, you will also find two functions. These functions inspect and query the data.  They are used in the ```main.py``` file to test looking up valid vehicle entries (such as motorcycles in "ITALIA NORD-OCCIDENTALE") as well as an invalid combination.

## Credits:

The data set is excerpt from a much larger one provided by the Automobile Club of Italy (ACI) representing the state of the Italian vehicle fleet in 2025. The full data set is publicly available on the ACI Autoritratti page:
